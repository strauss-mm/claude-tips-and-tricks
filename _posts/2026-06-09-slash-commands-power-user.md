## The Tip

Beyond `/help`, Claude Code has powerful slash commands that most users never discover:

| Command | What it does |
|---------|-------------|
| `/init` | Generate a CLAUDE.md for any project — instant context |
| `/review` | Full PR review with inline comments |
| `/compact` | Compress conversation to free up context window |
| `/fast` | Toggle fast mode (Opus with faster output) |
| `/cost` | Show token usage and cost for the session |
| `/memory` | View what Claude remembers about you |

## The Game-Changer: `/compact`

When you're deep in a long session and Claude starts losing context or repeating itself, hit `/compact`. It summarizes the conversation so far and frees up the context window — like a fresh start but with all the knowledge retained.

## DevSecOps Application

Start every new project with `/init` — it reads your codebase and generates a CLAUDE.md that teaches Claude about your project structure, build commands, and patterns. This means every future session starts with full context.

## Pro Tip

You can chain: after a big refactor, run `/compact` then `/review` to get a fresh-context review of your changes without prior conversation bias.
